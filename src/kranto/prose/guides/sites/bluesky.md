# A Bluesky post

- **300 graphemes.** Open on the reader's interest: a claim, a prediction or a question, then
  the fact. The first post of a thread stands alone.
- **A link card carries the link** when there is one, so the text need not repeat the address.
- **At most two tags, at the end,** and only tags the topic's own sources use.
- **Ask a real question or none.** Not: "Thoughts?" / "Who else is excited?"
