## What Kranto is

Kranto runs on your own Linux machine as one page in your browser, on 127.0.0.1. You name the
topics you follow; it proposes places to read and reads only the ones you tick. It keeps the few
items that matter, each with its link, in a library on your machine, writes a short cited brief a
day per topic and idea cards about what the news suggests, and drafts the post about it (your
blog, a newsletter, short posts for Bluesky, Mastodon, X, Threads and LinkedIn) in your voice.
**Nothing is posted until you say yes.** Your own Claude Code can work beside every page as the
console.

## What 0.7.0 is

The first release. Earlier builds were nightly pre-releases for testing; this is the one the
install lines take.

## What it needs

- Linux, Python 3.12 and [uv](https://docs.astral.sh/uv/) (`install.sh` installs uv for you if
  it is missing), and bubblewrap (`bwrap`): the post writers run in its sandbox. `kranto setup`
  checks each and prints your distribution's command for what is missing.
- One model for reading: an Anthropic or OpenRouter key, another OpenAI-compatible endpoint, or
  your Claude Code login. Every call is metered; no spend cap is set unless you set one.
- For the console: the Claude Code command line, signed in. Kranto works without it.
- No GitHub account and no package index: the release's files are downloaded from this page and
  every hash is checked.

## How to install

```
curl -fsSL https://github.com/iddv/kranto/releases/latest/download/install.sh | sh
```

or the lines under **Install** below, which name this release exactly. To read the script
first, download `install.sh`, read it, then `sh install.sh`. It installs the `kranto` command,
then `kranto setup` asks for a model and starts Kranto; `kranto open` signs your browser in.
[docs/setup.md](https://github.com/iddv/kranto/blob/v0.7.0/docs/setup.md) has every step and the
by-hand way.

## Known limits

- Linux only: not macOS, not Windows. One person on one machine, on loopback: not a hosted
  service, not for teams, no phone app.
- The costs in the README and the quality of the idea cards were measured on one install, the
  maintainer's; they are not proved for anyone else.
- Posting to the sites for real needs your own app or token for each, and the sites' terms
  change; it was rehearsed with stand-ins
  ([docs/accounts.md](https://github.com/iddv/kranto/blob/v0.7.0/docs/accounts.md)).
- The console runs Claude Code as you, not in a sandbox
  ([docs/threat-model.md](https://github.com/iddv/kranto/blob/v0.7.0/docs/threat-model.md)); a
  new install's console asks before every edit and command.
- Until 1.0 anything may change, settings included; `kranto update --rollback` goes back one
  release.

The whole list of what is in it is in
[CHANGELOG.md](https://github.com/iddv/kranto/blob/v0.7.0/CHANGELOG.md).

## If you ran it before it was called Kranto

An install made before the rename updates to this release from the nightly build that crossed it
over (`kranto update`); its data, settings, connections, service and old command are kept, and
`kranto update --rollback` goes back.
